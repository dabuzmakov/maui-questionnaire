# Домашнее задание №1 — «Анкета»

> Разработайте .NET MAUI-приложение с анкетой на самостоятельно выбранную тему. Вопросы, варианты ответов и оформление придумайте сами.

## Обязательные контролы и атрибуты

Указанные свойства необходимо задать явно в XAML. Для событий следует подключить работающие обработчики.

| Контрол | Минимальное количество | Обязательные свойства и события |
|---|:---:|---|
| `Label` | 2 | `Text`, `FontSize`, `FontAttributes` |
| `Entry` | 2 | `Placeholder`, `Keyboard`, `MaxLength` |
| `Editor` | 1 | `Placeholder`, `AutoSize`, `MaxLength` |
| `Picker` | 1 | `Title`; минимум 3 варианта в `Items` или `ItemsSource` |
| `RadioButton` | 3 в одной группе | `Content`, `GroupName`, `Value` |
| `CheckBox` | 2 | `IsChecked`, `Color` |
| `Switch` | 1 | `IsToggled`, `OnColor` |
| `DatePicker` | 1 | `Format`, `Date`, `MinimumDate`, `MaximumDate` |
| `Slider` или `Stepper` | 1 | `Minimum`, `Maximum`, `Value`; для `Stepper` также `Increment` |
| `Image` | 1 | `Source`, `Aspect`, `HeightRequest` |
| `Button` | 2 | `Text`, `Clicked` |

## Требования к разметке

- [ ] Использовать `Grid` с явно заданными `RowDefinitions` и `ColumnDefinitions`.
- [ ] Для дочерних элементов `Grid` указать `Grid.Row` и `Grid.Column`.
- [ ] Использовать `VerticalStackLayout` или `HorizontalStackLayout` с заданным `Spacing`.
- [ ] Задать `Margin` у элементов и `Padding` у контейнера.
- [ ] Поместить анкету в `ScrollView`, чтобы все поля оставались доступными на небольшом экране.
- [ ] Задать `x:Name` элементам, к которым обращается C#-код или привязка.

## Требования к поведению

- [ ] Создать минимум одну привязку между элементами через `x:Reference`, явно указав `Path` и `Mode`.
- [ ] Изменять `IsVisible` или `IsEnabled` в зависимости от заполнения анкеты.
- [ ] Кнопкой **«Показать результат»** проверять минимум два обязательных поля и выводить сводку всех ответов.
- [ ] Кнопкой **«Очистить»** возвращать поля и результат в исходное состояние.
- [ ] Разместить логику обработчиков в code-behind.

## Дополнительное условие

Для двух элементов `Entry` необходимо задать разные значения `Keyboard`. Начальные значения даты и числовых контролов должны находиться внутри указанных диапазонов.
